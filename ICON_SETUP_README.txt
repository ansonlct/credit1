W!bate icon integration package

Upload the contents of this folder to the same GitHub repository root.
Keep the relative paths unchanged:
- index.html
- favicon.ico
- apple-touch-icon.png
- site.webmanifest
- browserconfig.xml
- icons/

Included icon coverage: favicon, iOS / iPadOS, Android / PWA adaptive maskable, and Windows tiles.
